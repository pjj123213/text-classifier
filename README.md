# 基于朴素贝叶斯的中文电影评论情感分类器

本项目使用 Python **从零实现多项式朴素贝叶斯（Multinomial Naive Bayes）分类器**，对豆瓣电影短评进行正、负面二分类。项目包含从 SQLite 数据库读取评论、文本清洗、中文分词、数据采样、模型训练以及指标评估的完整流程。

> 本项目没有直接调用 `sklearn.naive_bayes` 中的现成模型；朴素贝叶斯的词频统计、先验概率、条件概率、拉普拉斯平滑和预测逻辑均在 `text_classifier.py` 中手动实现。`scikit-learn` 仅用于数据集划分和评估。

## 功能特点

- 从 SQLite 数据库读取电影及其评论数据
- 按评分自动构造情感标签
- 清除 HTML 标签、URL 和特殊符号
- 使用 `jieba` 进行中文分词
- 限制每部电影最多采样 40 条评论，降低热门电影造成的数据偏斜
- 按电影划分训练集与测试集，避免同一部电影的相似评论同时出现在两者中
- 手写多项式朴素贝叶斯，并使用拉普拉斯平滑和对数概率避免数值下溢
- 输出 Accuracy、Precision、Recall 和 F1-score

## 分类规则

| 原始评分 | 处理方式 | 标签 |
| --- | --- | --- |
| 1～2 星 | 负面评论 | `0` |
| 3 星 | 中性评论，不参与训练和测试 | — |
| 4～5 星 | 正面评论 | `1` |

## 项目结构

```text
.
├── README.md             # 项目说明
├── douban.db             # SQLite 电影评论数据集
└── text_classifier.py    # 数据处理、模型训练和评估代码
```

数据库中与本项目直接相关的表如下：

- `movie`：电影信息，主键为 `ID`
- `comment`：评论信息，通过 `MOVIEID` 与 `movie.ID` 关联，包含 `RATING` 和 `CONTENT`

脚本只读取电影名称、评论正文和评分，不使用评论者信息。

## 处理流程

1. 使用 SQL 将 `comment` 表与 `movie` 表关联，读取电影名称、评论内容和评分。
2. 删除 3 星中性评论，并按照评分生成二分类标签。
3. 删除评论正文为空的数据，以及同一电影下内容重复的评论。
4. 随机打乱数据，并为每部电影最多保留 40 条评论。
5. 去除 HTML、URL 和特殊字符，再使用 `jieba` 分词。
6. 以电影为单位按 8:2 划分训练集和测试集，而不是直接随机拆分评论。
7. 根据训练集统计类别先验概率和类别内词频。
8. 使用拉普拉斯平滑计算条件概率，并转换为对数形式。
9. 对测试集逐条预测，输出分类指标。

## 模型原理

对于分词后的评论 $d=(w_1,w_2,\ldots,w_n)$，模型选择后验概率最大的类别：

$$
\hat{c}=\underset{c}{\arg\max}\left[\log P(c)+\sum_{i=1}^{n}\log P(w_i\mid c)\right]
$$

其中，条件概率采用加一平滑：

$$
P(w\mid c)=\frac{N_{w,c}+1}{N_c+|V|}
$$

- $N_{w,c}$：词 $w$ 在类别 $c$ 中出现的次数
- $N_c$：类别 $c$ 的总词数
- $|V|$：训练集词表大小

计算时使用对数概率，将概率连乘转换为对数相加，从而减少浮点数下溢问题。测试集中未在训练词表出现的词会被忽略。

## 数据集说明

原始数据来源：[douban.zip](https://gitcode.com/open-source-toolkit/a237a/blob/main/douban.zip)。当前仓库中的 `douban.db` 约为 75 MB；数据库共有 404,972 条评论，脚本通过 `movie.ID = comment.MOVIEID` 可关联到其中 253,480 条，覆盖 489 部电影。经过标签过滤、去重和每部电影最多 40 条的采样后，实际进入模型的数据为 19,480 条。

数据的著作权和使用许可归原始提供方所有。本项目仅用于学习与研究；公开发布或用于其他场景前，请自行确认原始数据的许可范围，并检查数据库中是否存在不适合公开分发的信息。

## 已知限制与改进方向

- 当前模型采用词袋假设，不考虑词序和上下文语义。
- 未引入停用词、否定词处理或 n-gram 特征。
- 未提供交互式单条评论预测接口，也未持久化训练后的模型。
- 类别先验未做平滑；如果训练集中某个类别完全缺失，训练会失败。
- 数据库路径和采样参数目前直接写在脚本中，后续可改为命令行参数。
- 可进一步尝试 TF-IDF、特征选择、逻辑回归、支持向量机或预训练中文模型，并比较效果。
